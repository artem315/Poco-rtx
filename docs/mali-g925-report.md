# Проверка шейдеров PocoRTX 2 под GPU POCO X8 Pro Max

Все шейдеры мода скомпилированы **Arm Mali Offline Compiler v2026.3.0** (драйвер Mali
**r56p0**) под **Immortalis-G925** — GPU POCO X8 Pro Max — в том виде, в каком их получает
драйвер телефона:

- три ядра аппаратной трассировки лучей — как SPIR-V для Vulkan (compute + `VK_KHR_ray_query`);
- проходы шумоподавления, сведения и эффектов шейдеров — как SPIR-V для Vulkan-бэкенда игры;
- эффекты шейдеров на OpenGL — через **настоящий конвертер LTW** (основной рендерер
  MJ Launcher), потому что на OpenGL мод включает только их.

Результат: **все шейдеры компилируются без ошибок**, а для ядер трассировки компилятор
сообщает `Has slow ray traversal: false` — обход лучей идёт на аппаратных блоках
трассировки Immortalis, а не программной эмуляцией (так это свойство описывает Arm:
[руководство по трассировке лучей на Android](https://learn.arm.com/learning-paths/mobile-graphics-and-gaming/ray_tracing/rt09_optimizing/)).

Такты — суммарные по всем инструкциям (A — арифметика, LS — загрузка/сохранение,

(число лучей и шагов приходит из настроек), а время самого обхода лучей в такты
не входит вовсе — его делает отдельный аппаратный блок.

## Вытеснение регистров в ядрах трассировки

Ядра используют все 64 регистра и часть состояния держат в стеке. Чтобы понять, сколько
из этого — сам механизм ray query в драйвере Mali, а сколько — код мода, скомпилированы
два минимальных шейдера:

| Шейдер | Регистры | Стек, байт |
|---|---|---|
| один непрозрачный луч | 64 | 96 |
| один луч с альфа-тестом (листва) | 64 | 400 |
| `rt_light` (первичный луч, AO, тени, объёмный свет) | 64 | 464 |
| `rt_indirect` (GI, свечение, блики) | 64 | 576 |
| `rt_reflect` (отражения, вода, стекло) | 64 | 560 |

То есть основная часть стека — это состояние запроса луча с альфа-тестом в драйвере, код
мода добавляет к нему 60–180 байт. Изначально трассировка была одним ядром, которое
вытесняло 690 байт и тратило 730 тактов LS; после разделения на три ядра LS-нагрузка
каждого — 121–367 тактов. Лучи, которым прозрачность текстур не нужна (AO, GI, объёмный
свет), идут как непрозрачные — это самый дешёвый вариант на Mali. Тени сквозь листву
(альфа-тест) отключаются в настройках («Тени листвы»).

## Чего эта проверка не показывает

Офлайн-компилятор подтверждает, что драйвер телефона примет шейдеры и выполнит
трассировку на аппаратных блоках, но **не измеряет FPS**: скорость обхода лучей зависит от
сцены и самого GPU. Настоящий FPS на POCO X8 Pro Max можно узнать только на телефоне.
Если не хватает — начните с качества «Низкое» и дальности RT 2–3 чанка.

Повторить: `malioc -c Immortalis-G925 --vulkan <kernel>.spv` (SPIR-V собирается задачей
`./gradlew compileRtShaders`).
